# Test data

- `fonts/UVSTest.ttf`, `fonts/IBM Plex Serif-Text-FL.ttf`,
  `fonts/IBM Plex Serif-Text-ufo2ft.ttf` and `stream/IBM Plex
  Serif-Text-FL.fpgm.{ttxasm,vttasm}` are copied from ufo-extractor's test data
  (https://github.com/robotools/extractor, commit c592006, MIT license, see
  `extractor-License.txt`). IBM Plex is licensed under the SIL Open Font
  License 1.1.
- `expected/*.ufo` and `stream/sample*.{bin,ttxasm}` are generated by
  `regenerate.py` with ufo-extractor 0.8.1, fontFeatures 1.9.0, fontTools
  4.61.1 and ufoLib2 0.18.1. extractor's own checked-in
  `*_extracted.ufo` files are not used: they predate anchor and feature
  extraction and were saved with defcon, so current extractor no longer
  reproduces them.
- `set_order_cases.txt` and `tuple_set_cases.txt` hold CPython 3.14 set
  iteration orders (`list(set(values))`, `set(values).pop()`) for random
  inputs, used by the unit tests in `src/pyfmt.rs`.
- `codec_cases.json` and `filename_cases.json` are generated by
  `regenerate.py`.
- `codec_cases.json` holds random byte strings and how Python decodes them
  with each legacy name-record codec, used by the unit test in
  `src/codecs/mod.rs`.
- `filename_cases.json` holds glyph names and the `.glif` file names
  fontTools 4.61.1's `userNameToFileName(name, existing, suffix=".glif")`
  gives them in sequence (clashes, reserved names, truncation), used by the
  unit test in `src/ufo.rs`.
